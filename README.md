# Денис Мазур

Руководитель проектов в разработке ПО. LLM применяю с начала 2023 года, с 2025-го
внедряю AI-инструменты в команды: инференс, плагины в VS Code, AI-агенты в повседневной
разработке.

## Что здесь можно посмотреть

### RAG и LLM-приложения

- **[telegram_bot_ai](https://github.com/uboy/telegram_bot_ai)**. Telegram-ассистент с RAG: база знаний из файлов и веб-скраперов, FAISS + sentence-transformers, цитаты источников.
- **[astrolab](https://github.com/uboy/astrolab)**. Telegram-бот на LLM: HR-модуль проверки кандидатов по резюме (docx/pdf/md) и развлекательные сценарии.
- **[InsightAudio](https://github.com/uboy/InsightAudio)**. Полностью локальная транскрипция аудио и видео со структурированными пересказами.
- **[VoxFusion](https://github.com/uboy/VoxFusion)**. Захват системного звука, транскрипция с диаризацией и переводом в реальном времени.

### Инструменты для AI-агентов

- **[AICodingAgentsAndSkills](https://github.com/uboy/AICodingAgentsAndSkills)**. Общие политики, скиллы и конфиги раннеров для AI-агентов (Claude Code, Codex, OpenCode).
- **[ai-workshop-demo](https://github.com/uboy/ai-workshop-demo)**. Демо-сервис для воркшопов по агентному кодингу с Claude Code.
- **[BuildHarbor](https://github.com/uboy/BuildHarbor)**. Оркестрация CI-сборок по PR: слоты на серверах, агенты, стриминг логов и артефактов.

### Инфраструктура и инженерные утилиты

- **[aegis-gateway](https://github.com/uboy/aegis-gateway)**. Единый edge-шлюз на порту 443: HAProxy TLS-SNI, WireGuard, реверс-прокси, SSH-hardening.
- **[xts-selector](https://github.com/uboy/xts-selector)**. Impact-analysis и выборочный запуск тестов XTS для OpenHarmony ArkUI.
- **[scr_hdc](https://github.com/uboy/scr_hdc)**. Зеркалирование экрана и удалённое управление устройствами HarmonyOS по HDC.
- **[coding_statistics](https://github.com/uboy/coding_statistics)**. Сбор статистики разработки из Git-сервисов и Jira.
- **[weather-informer](https://github.com/uboy/weather-informer)**. Автономный погодный киоск для старых Android-планшетов.
